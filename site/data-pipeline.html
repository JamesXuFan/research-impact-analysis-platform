Data Pipeline Close-Reading数据管道精读

From 8 raw Excel files to a DataFrame you can use directly on a Streamlit page, there are 5 layers of code and 18 functions in between. These notes take them apart function by function — what each one does, which pandas syntax it uses, and why it's written this way rather than the more "obvious" alternative. Read it in code order and you'll have covered pandas' most common operations (boolean indexing, groupby, astype, pd.cut, mask/where...) end to end. 从8个原始Excel文件到能在Streamlit页面上直接用的DataFrame，中间一共5层代码、 18个函数。这份笔记逐个函数拆开讲——每个函数在做什么、用到了哪些pandas语法、 以及为什么这么写而不是更"直觉"的写法。跟着代码顺序读一遍，pandas里最常用的那批 操作（布尔索引、groupby、astype、pd.cut、mask/where……）基本就覆盖全了。

01

Ingest layer摄入层

src/p36/ingest.py

Reads each of the 8 universities' Excel files, handling three traps that would otherwise quietly corrupt every downstream analysis — "the header isn't row 1," "Excel guesses ID columns are numbers," "missing values are written as a dash" — and concatenates them into one big table. 把8个大学各自的Excel文件读进来，处理"表头不在第一行""ID列被Excel猜成数字" "缺失值写成短横线"这三类会让后面所有分析悄悄算错的坑，拼成一张大表。

load_university_export(path)

Reads one university's Excel file, returns a clean DataFrame.读一个大学的Excel文件，返回干净的DataFrame。

# the arguments to pd.read_excel(...) are what actually control how it's read — this is the core of the functiondf = pd.read_excel(...) 的参数控制怎么读，是这个函数的核心
df = pd.read_excel(
    path,
    sheet_name="Sheet0",
    header=HEADER_ROW,                 # = 19, the real column names are on row 20 (0-indexed 19)= 19，真正的列名在第20行(0-indexed第19行)
    na_values=MISSING_VALUE_CODES,     # = ["-"], recognises the string "-" as missing= ["-"]，把字符串"-"识别成缺失值
    dtype={col: str for col in ID_COLUMNS},  # dict comprehension: force these columns to read as strings字典推导式：强制这些列读成字符串
)
df = df[df["EID"].notna()].reset_index(drop=True)
return df
  • header=19: tells pandas "skip the first 19 rows of blurb, row 19 (counting from 0) is the real column names" — omit it and the blurb gets read as a fake header.header=19：告诉pandas"跳过前19行说明文字，第19行(从0数)才是列名"——不写会把说明文字当成假表头。
  • na_values=["-"]: the source file writes missing values as the dash string, not a native empty Excel cell; without this argument "-" would be read as a genuine string, and every missing-value count would be wrong.na_values=["-"]：源文件缺失值写的是短横线字符串，不是Excel原生空单元格；不加这个参数，"-"会被当成一个真实字符串，缺失统计全错。
  • dtype={col: str for col in ID_COLUMNS}: a dict comprehension, equivalent to writing out {"EID": str, "Source ID": str, ...} by hand. It forces these ID columns to read as strings — without it, a column whose "single-value rows" Excel stores as int but whose "pipe-delimited rows" it stores as text ends up as a dirty mixed-type column pandas can't cleanly write to parquet later.dtype={col: str for col in ID_COLUMNS}：字典推导式，等价于手写一长串{"EID": str, "Source ID": str, ...}。强制这些ID列读成字符串——不强制的话，同一列里"纯数字的行"会被Excel存成int、"带竖线的组合ID行"存成文本，pandas猜出一列脏的混合类型，后面转parquot时才报错。
  • df["EID"].notna(): pulls out the EID column, tests each value for "is it non-null," returns an equal-length boolean Series.df["EID"].notna()：取出EID这一列，对每个值判断"是不是非空"，返回一个等长的布尔Series。
  • Boolean indexing df[boolean Series]: pandas' single most central filtering idiom, keeping only the rows where the corresponding position is True — used here to drop the two non-data rows at the end of the file (a blank row + a copyright notice) whose EID is empty.布尔索引 df[布尔Series]：pandas里最核心的筛选写法，只保留对应位置是True的行——这里用来去掉文件末尾EID为空的两行非数据行(空行+版权声明)。
  • .reset_index(drop=True): after filtering, row numbers have "holes" (e.g. 0,1,3,4) — this renumbers them into a clean 0,1,2,3...; drop=True means don't keep the old row numbers as a new column..reset_index(drop=True)：筛完之后行号有"洞"(比如0,1,3,4)，这个方法重新编号成连续的0,1,2,3...；drop=True表示不要把旧行号也存成一列。
university_name_from_filename(path)

Guesses the university's name from the filename — nothing to do with pandas, pure string handling.从文件名猜出大学名字，跟pandas无关，纯字符串处理。

prefix = "QS_World_University_Rankings_2027_-_Publications_at_"
return path.stem.removeprefix(prefix).replace("_", " ")
  • path.stem: a pathlib.Path attribute, the filename with the extension stripped off.path.stem：pathlib.Path的属性，取文件名去掉扩展名的部分。
  • .removeprefix(prefix): strips off the known fixed prefix..removeprefix(prefix)：把已知的固定前缀砍掉。
  • .replace("_", " "): underscores to spaces, giving the human-readable "University of Sydney.".replace("_", " ")：下划线换成空格，得到人可读的"University of Sydney"。
load_all_universities()

Reads all 8 universities' files, tags each, and concatenates them into one big table — no deduplication.把8个大学的文件全部读进来、打标签、拼成一张大表——不去重。

frames = []
for p in sorted(DATA_DIR.glob("*.xlsx")):
    df = load_university_export(p)
    df["source_university"] = university_name_from_filename(p)
    frames.append(df)
return pd.concat(frames, ignore_index=True)
  • DATA_DIR.glob("*.xlsx"): finds every .xlsx file in the folder; sorted() guarantees the same file order on every run, so the result is reproducible.DATA_DIR.glob("*.xlsx")：找出文件夹下所有.xlsx文件；sorted()保证每次运行文件顺序一致，结果可复现。
  • df["source_university"] = ...: the standard way to add a new column — tags this university's data, since once the 8 tables are concatenated there'd otherwise be no way to tell which school a row came from.df["source_university"] = ...：新增一列的标准写法——给这个大学的数据打标签，因为等下8张表拼在一起后，光看数据看不出原来是哪个学校的。
  • frames.append(df): collects each processed DataFrame into a list, to be concatenated all at once at the end (much faster than repeatedly concatenating onto one "growing" table).frames.append(df)：把处理好的DataFrame收集到一个list里，等全部读完再一次性拼接（比每次都跟一个"累积中的大表"拼接快得多）。
  • pd.concat(frames, ignore_index=True): stacks every DataFrame in the list row-wise into one big table; ignore_index=True renumbers the stacked rows continuously from 0, instead of keeping each university's own 0-based, duplicate-prone index.pd.concat(frames, ignore_index=True)：把list里所有DataFrame按行方向堆叠成一张大表；ignore_index=True让堆叠后的行号重新从0连续编号，而不是保留每个大学各自从0开始、会重复的旧索引。
Note: no deduplication here注意：这里不去重 A paper co-authored across universities appears once in each contributing university's file, and this function preserves that as-is — use this output as-is for one university's own output figures; for any Go8-aggregate number, deduplicate_by_eid below must be called first. 跨校合作发表的论文会在每个参与大学的文件里各出现一次，这个函数原样保留——算某个 大学自己的产出用这份结果；算Go8整体数字，必须先调用下面的 deduplicate_by_eid。
deduplicate_by_eid(df)

Deduplicates on the paper's unique EID, producing a "one row per publication" version.按论文唯一编号EID去重，得到"一篇论文只算一次"的版本。

return df.drop_duplicates(subset="EID", keep="first").reset_index(drop=True)
  • .drop_duplicates(subset="EID", keep="first"): judges duplication only on the EID column (not requiring the whole row to match); of the duplicate rows, only the first occurrence is kept..drop_duplicates(subset="EID", keep="first")：只按EID这一列判断是否重复（不要求整行完全一样）；重复的多行里只保留第一次出现的那一行。
  • Because the 8 files were read in alphabetical sorted() order, "first occurrence" effectively means alphabetical-by-university-name decides which version survives — this doesn't affect downstream statistics, since an aggregate only cares that a paper exists, not which university's name it happens to be filed under.因为8个文件是按字母顺序sorted()读的，"第一次出现"其实是按大学名排序决定保留哪个版本——这不影响后续统计，因为汇总关心的是"这篇论文存在"，不关心归在哪个大学名下。
Measured numbers实测数字 385,664 raw rows → 327,265 unique publications after dedup: 46,969 (15.1%) are cross-university duplicates, one of them appearing in 7 of the 8 files simultaneously. This is exactly why every analysis function explicitly takes a "raw" or "deduplicated" argument by name, never a bare df. 385,664行原始数据 → 去重后327,265篇唯一论文：46,969篇(15.1%)是跨校重复， 其中一篇甚至同时出现在8个文件中的7个里。这就是为什么每个分析函数都明确接收 "raw"或"deduplicated"参数，从不接收一个含糊的df。

Dtype Cleanup类型清洗

src/p36/cleaning/dtypes.py

Kept separate from the ingest layer on purpose: ingest.py only fixes what would otherwise be misread outright (ID columns turning into float, "-" being read as a literal string); this layer applies the dtype casts documented as "processing rules" in the data dictionary — a cleaning convention, not a read-time safety net. 跟摄入层分开是有意为之：ingest.py只修"不修就直接读错"的问题(ID列变float、 "-"被当成字符串)；这一层做的是数据字典里记录为"处理规则"的类型转换，属于 "清洗规范"而不是"读取兜底"。

apply_canonical_dtypes(df)

Casts count-like columns — publication counts, citation counts, etc. — from float64 to a uniform nullable integer type.把发文量、引用数等计数类列，从float64统一转成可空整数类型。

df = df.copy()
for col in INT_COLUMNS:
    if col in df.columns:
        df[col] = df[col].astype("Int64")
return df
  • df.copy(): copies first, then modifies — never mutates the caller's original DataFrame, avoiding the "function silently changed data outside itself" side effect; a standard defensive pattern in pandas.df.copy()：先复制一份再改，不修改调用者手里的原始DataFrame——避免"函数悄悄改了外面的数据"这种副作用，pandas里的标准防御写法。
  • if col in df.columns: checks the column exists first, so the function can safely be called on "a subset with only a few columns" without raising a KeyError over a missing one.if col in df.columns：先检查列存不存在，这样函数可以安全地用在"只挑了几列的子集"上，不会因为列缺失报KeyError。
  • .astype("Int64"): capitalised Int64 is pandas' nullable integer extension dtype, able to hold both integers and the missing value pd.NA; lowercase int64 is the native numpy type, which can't hold missing values — since these columns (publication count, citation count, institution count...) genuinely do have missing values, the capitalised version is required..astype("Int64")：大写Int64是pandas的可空整数扩展类型，能同时装整数和缺失值pd.NA；小写int64是numpy原生类型，装不下缺失值——这批列(发文量、引用数、机构数……)确实会有缺失，所以必须用大写版本。

src/p36/build_dataset.py

Chains the first two layers into one command: python -m p36.build_dataset. Only needs re-running when data/*.xlsx changes. 把前两层串成一条命令：python -m p36.build_dataset。只有 data/*.xlsx 变化时才需要重新跑一次。

Load → cast dtypes → dedupe → write to disk, run start to finish in one go, printing progress numbers along the way.加载 → 转类型 → 去重 → 写盘，一次性跑完，边跑边打印进度数字。

df = load_all_universities()

df.to_parquet(RAW_PATH, index=False)
deduped.to_parquet(DEDUPED_PATH, index=False)
  • df['source_university'].nunique(): counts how many distinct values this column has (should be 8).df['source_university'].nunique()：统计这一列有多少个不同的值(应该是8)。
  • f"...{len(df):,}...": the :, inside an f-string is a format spec that adds thousands separators — 385664 prints as 385,664.f"...{len(df):,}..."：f-string里:,是格式化说明符，给数字加千位分隔符，385664会打印成385,664。
  • PROCESSED_DIR.mkdir(parents=True, exist_ok=True): pathlib creates the folder; parents=True creates parent directories too if missing, exist_ok=True doesn't raise if the folder already exists.PROCESSED_DIR.mkdir(parents=True, exist_ok=True)：pathlib创建文件夹；parents=True上级目录不存在也一起创建，exist_ok=True文件夹已存在也不报错。
  • df.to_parquet(RAW_PATH, index=False): writes the DataFrame to a parquet file; index=False means don't also save pandas' auto-generated row numbers, or reading it back would gain a useless extra index column.df.to_parquet(RAW_PATH, index=False)：把DataFrame写成parquet文件；index=False表示不要把pandas自动生成的行号也存进文件，不然读回来会多一列没用的索引。

Read Layer读取层

src/p36/dataset.py

The only module day-to-day analysis code needs to touch — it just reads back the parquet files build_dataset.py wrote, as DataFrames; it does no cleaning or computation itself. 日常写分析代码时唯一需要打交道的模块——只负责把build_dataset.py写好的parquet 文件读回DataFrame，本身不做任何清洗或计算。 

# top of the module: local dev vs. deployed to Azure point at different data locations模块顶部：本地开发 vs 部署到Azure，指向不同的数据存放位置
PROCESSED_DIR = Path(os.environ.get("P36_DATA_DIR", str(_DEFAULT_PROCESSED_DIR)))
RAW_PATH = PROCESSED_DIR / "publications_raw.parquet"
DEDUPED_PATH = PROCESSED_DIR / "publications_deduplicated.parquet"
  • os.environ.get("P36_DATA_DIR", default): reads an environment variable, falling back to the default if unset — locally the variable isn't set, so it uses the repo's data/processed/; on Azure the variable is set, pointing at the server's persistent storage path.os.environ.get("P36_DATA_DIR", 默认值)：读取一个环境变量，没设置就用默认值——本地没设这个变量，走仓库里的data/processed/；线上Azure设了这个变量，指向服务器持久存储路径。
  • Path(...) / "filename": pathlib's / operator joins paths, safer than string concatenation and handles cross-OS slash differences automatically.Path(...) / "文件名"：pathlib用/运算符拼路径，比字符串拼接更安全，自动处理不同操作系统的斜杠差异。
load_raw()

Reads the non-deduplicated version — used for one university's own output figures.读未去重版——算某一所大学自己的产出数字时用这个。

if not RAW_PATH.exists():
    raise FileNotFoundError(f"{RAW_PATH} does not exist yet. Run `python -m p36.build_dataset` first.")
return pd.read_parquet(RAW_PATH)
  • RAW_PATH.exists(): a pathlib method checking whether the file exists — calling this before the dataset is built gives a clear "go run build_dataset first" error instead of a vague file-not-found exception.RAW_PATH.exists()：pathlib方法，检查文件是否存在——没建库就直接调用，会得到一条明确告诉你"先去跑build_dataset"的报错，而不是一个含糊的文件找不到异常。
  • pd.read_parquet(RAW_PATH): the parquet counterpart to pd.read_excel, reading many times faster (columnar storage format, no per-cell parsing).pd.read_parquet(RAW_PATH)：pd.read_excel的parquet版本，读取速度快很多倍(列式存储格式，不用逐单元格解析)。
load_deduplicated()

Reads the deduplicated version — required for any Go8-aggregate or cross-university figure, mirroring load_raw() exactly.读已去重版——算Go8整体或跨校对比数字时必须用这个，逻辑跟 load_raw() 完全对称。

Which one to use — the rule is unambiguous选哪个，规则很明确 For one university's own output (e.g. "how many did Sydney publish") → load_raw(); for Go8-aggregate or cross-university comparisons (e.g. "how many did the 8 universities publish in total," "where does Sydney rank in the Go8") → load_deduplicated() is mandatory, or cross-university co-authored papers get double-counted and the number runs high. 算某一所大学自己的产出(比如"悉尼发了多少篇")→ load_raw()； 算Go8整体或跨校对比(比如"8所学校总共发了多少篇"、"悉尼在Go8里排第几")→ 必须 load_deduplicated()，否则跨校合著论文被重复计数，数字偏高。

Metrics Layer指标层

src/p36/metrics/metrics.py

Building the dataset stops here, but "usable" needs one more step — columns like is_q1, is_international that every analysis needs don't live in the parquet files; they're computed fresh on every load. That way a definition only ever needs changing in one place, and "the definition stored in the parquet" can never drift from "the definition in the code." 数据"建库"到这里就结束了，但"能用"还差一步——is_q1、is_international这些 分析要用的标记列不存在parquet文件里，是每次加载后现算的。这样定义只需要改 一处代码，不会出现"parquet里存的定义"和"代码里的定义"哪天对不上的问题。

add_derived_flags(df)

Adds every boolean flag column the whole platform needs, in one pass (is_q1, is_international, is_uncited...).一次性加上全平台都要用的布尔标记列(is_q1、is_international、is_uncited……)。

df = df.copy()
df["is_retracted"] = df["Publication type"] == "Retracted"

# is_q1 is special: it has to distinguish "not Q1" from "no CiteScore percentile at all"is_q1 比较特殊：要区分"不是Q1"和"根本没有CiteScore百分位数据"两种情况
is_q1 = (df[CITESCORE_PERCENTILE_COL] <= Q1_CITESCORE_PERCENTILE_MAX).astype("boolean")
df["is_q1"] = is_q1.mask(df[CITESCORE_PERCENTILE_COL].isna())

df["is_top_decile"] = (df[TOP_CITATION_PERCENTILE_COL] <= TOP_DECILE_PERCENTILE_MAX).astype(bool)
df["is_international"] = (df[COUNTRIES_COL] >= INTERNATIONAL_COLLABORATION_MIN_COUNTRIES).astype(bool)
df["is_uncited"] = (df["Citations"] == 0).astype(bool)
if OPEN_ACCESS_NULL_MEANS_NOT_OA:
    df["is_open_access"] = df["Open Access"].notna()
return df
  • df["Publication type"] == "Retracted": a comparison operator applied to a whole column, element by element, returning an equal-length boolean Series — assigning it directly is the new column.df["Publication type"] == "Retracted"：比较运算符作用在整列上，逐个元素比较，返回一个等长的布尔Series，直接赋值就新增了一列。
  • The single most important line: .mask(cond) — a pandas method meaning "wherever cond is True, replace with a missing value," the opposite of .where() (.where(cond) means "keep where cond is True, everything else becomes missing"). Used here to turn "the CiteScore percentile is itself null" from being misread as False ("not Q1") back into a genuine missing value (pd.NA, meaning "Q1 status undefined") — skip this step and "no percentile data" silently gets conflated with "has percentile data but isn't Q1."最关键的一行：.mask(条件) —— pandas方法，"条件为True的位置，替换成缺失值"，是.where()的反义词(.where(cond)是"cond为True的位置保留，其它变缺失")。这里用来把"CiteScore百分位本身就是空的"这种情况，从"被误判成False(不是Q1)"改回真正的"缺失"(pd.NA，意思是"Q1状态未定义")——如果漏了这一步，"没有百分位数据"和"有百分位数据但不是Q1"会被悄悄混成同一类。
  • .astype("boolean") (capital B): pandas' nullable boolean extension dtype, able to hold True/False/pd.NA; the plain comparison result cast with .astype(bool) (lowercase, only True/False) would force NaN into False too, exactly what needs avoiding here..astype("boolean")(大写B)：pandas的可空布尔扩展类型，能装True/False/pd.NA三种值；比较运算的原始结果加.astype(bool)(小写，只有True/False)会强制把NaN也变成False，这正是要避免的。

pandas Syntax Cheat Sheetpandas 语法速查表

A round-up of the syntax points that keep recurring above, grouped by "what it does" rather than order of appearance.把上面反复出现的语法点收一遍，按"做什么"分类，而不是按出现顺序。

Boolean indexing df[cond]布尔索引 df[cond]
Filters rows with a True/False sequence the same length as df, keeping only the True positions. The single most-used filtering idiom in the whole project, no close second.用一个跟df等长的True/False序列筛选行，只留下True的位置。整个项目里最常用的筛选手法，没有"之一"。
New column df["new"] = ...新增列 df["新列"] = ...
Give a Series the same length as df on the right (or a broadcastable scalar/expression), and a plain assignment becomes a new column — no separate declaration needed.右边给一个跟df等长的Series(或能广播的标量/表达式)，直接赋值就成了新的一列，不需要额外声明。
.astype(dtype)
Force-casts an entire column's dtype. Case matters: "Int64"/"boolean" (capitalised, pandas nullable extension types, can hold missing values) vs. bool/int64 (native python/numpy types, cannot).强制转换整列的数据类型。区分大小写："Int64"/"boolean"(大写，pandas可空扩展类型，能装缺失值)vsbool/int64(python/numpy原生类型，装不下缺失值)。
.groupby(col).size()
Groups by one column's values, counting rows per group. To sum/mean a numeric column instead of counting rows, use .groupby(col)["numeric_col"].sum()/.mean().按某一列的值分组，数每组有多少行。想对某一数值列求和/求均值而不是数行数，用.groupby(col)["数值列"].sum()/.mean()。
.mask(cond) / .where(cond)
Opposites: where keeps where cond is True, everything else becomes missing; mask turns where cond is True into missing, keeping the rest.互为反义：where保留cond为True的部分，其余变缺失；mask是cond为True的部分变缺失，其余保留。
pd.cut(col, bins, labels)
Cuts continuous numbers into a categorical variable by interval. Intervals default to "open-closed"; include_lowest=True lets the minimum value be captured by the first interval too.把连续数值按区间切成分类变量。默认区间是"开-闭"，include_lowest=True让最小值也能被第一个区间收进去。
(boolean Series).mean()(布尔Series).mean()
True=1, False=0, so the mean is "the share meeting the condition" — no need to hand-write sum()/len().True=1、False=0，均值就是"满足条件的比例"——不用手写sum()/len()。
.drop_duplicates(subset=col, keep="first")
Judges duplication on the specified column only (not the whole row); of duplicates, keeps only the first occurrence.只按指定列判断是否重复(不要求整行相同)，重复的只保留第一次出现的一行。
pd.concat([df1, df2, ...])
Stacks multiple DataFrames row-wise into one. ignore_index=True renumbers the stacked rows continuously.把多个DataFrame按行方向堆叠成一个。ignore_index=True让堆叠后的行号重新连续编号。
.reset_index(drop=True)
After filtering/dedup, row numbers often have "holes"; renumbers them into a clean 0,1,2...; drop=True means don't keep the old row numbers.筛选/去重后行号常有"洞"，重新编号成连续的0,1,2...；drop=True表示不保留旧行号。
.dropna() / .notna() / .isna()
Respectively: "discard rows/elements with missing values," "test for non-null" (returns boolean), "test for null" (returns boolean, complementary to notna).分别是"丢弃缺失值所在的行/元素"、"判断是否非空"(返回布尔)、"判断是否为空"(返回布尔，跟notna互补)。
col.between(lo, hi)
Tests whether a value falls in the closed interval [lo, hi], equivalent to two comparisons joined with &, but more concise.判断值是否落在[lo, hi]闭区间内，等价于两个比较用&连接，但更简洁。
.nunique()
Counts how many distinct values a column has (missing values excluded automatically).数一列里有多少个不同的值(自动排除缺失值)。
.iloc[i] vs .loc[label]
iloc takes values by position (which row/column, counting from 0); loc takes values by index label (e.g. by year, by university name). The two can coincide when the label equals the position, but they mean entirely different things.iloc按位置取值(第几行/第几列，从0数)；loc按索引标签取值(比如按年份、按大学名)。名字或数值恰好等于位置时两者结果可能相同，但含义完全不同。
pd.read_parquet / .to_parquet
Read/write for the columnar storage format, much faster than Excel/CSV, and preserves pandas extension dtypes (e.g. Int64) without loss.列式存储格式的读写，比Excel/CSV快得多，且能保留pandas的扩展dtype(比如Int64)不失真。
Dict comprehension {k: v for k in ...}字典推导式 {k: v for k in ...}
Not pandas-specific, but used repeatedly in the project for dtype={col: str for col in ID_COLUMNS}-style "apply the same treatment to a batch of columns" scenarios.不是pandas专属，但项目里频繁用在dtype={col: str for col in ID_COLUMNS}这种"给一批列统一指定同一种处理方式"的场景。
